RAJASHREE & SHAMA — WEDDING INVITATION

GitHub Pages hosting:
1. Extract this ZIP file.
2. Create a new GitHub repository.
3. Upload index.html, style.css, script.js and couple-reference.jpg.
4. Open Settings > Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Select the main branch and /(root), then click Save.

Important: Upload the four website files directly, not the outer folder.

To change the date, time or venue, open index.html and replace the words
"Coming soon" and "to be announced" with the correct details.
